# Glossary

Shared vocabulary. Use these terms consistently in every note.

| Term | Definition |
|---|---|
| **Cell** | A single module of the system. Most cells are planter cells; some have special roles (Heart, Brain, Light...). |
| **Planter cell** | A cell holding one planting in its growing medium, individually watered, fed and sensed. |
| **Hive** | A connected arrangement of cells on a wall that operates as one system. |
| **Heart** | The cell (or role) responsible for supplying and circulating water and nutrient solution. |
| **Brain** | The cell (or role) that senses, decides and coordinates the hive and connects to the owner. |
| **Joining** | The act of adding a cell to a hive, after which it is automatically part of the plumbing and controls. |
| **Link** | The connection between neighbouring cells (physical, water, power, data). |
| **Substrate** | The growing medium in a planter cell (soil mix, bark, LECA, moss, etc.), matched to the plant. |
| **Care profile** | A plant-specific set of care needs (water, nutrients, light) assigned to a planter cell. |
| **Recipe** | An expert-level, editable care profile, potentially shared with others. |
| **Nutrient solution** | Water with dissolved fertiliser, delivered by the Heart. |
| **Autopilot / Guided / Expert** | The three autonomy levels; see [[System Concept#Levels of autonomy]]. |
| **Starter hive** | The entry purchase: Heart, Brain and a small set of planter cells. |
