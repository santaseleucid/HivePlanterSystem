# The Hive — Modular Living Wall (working name)

This repository is an **Obsidian vault** holding the business, design, and engineering documents for a modular, self-regulating planter system: planter *cells* that join together into a *hive* on a wall — part wall art, part fully automated garden.

## Getting started
1. Clone the repo.
2. In Obsidian: **Open folder as vault** → select this folder.
3. Start at [[Home]] (`Home.md`).
4. Enable the core **Templates** plugin (Settings → Core plugins) — templates live in `Templates/`.

## Conventions
- **Vision is constraint-free.** Notes in `01 Vision/` describe the ideal experience. No part numbers, vendors, costs, or prototype limitations there — those live in `03 Prototyping/` and `04 Engineering/`.
- Link generously with `[[wikilinks]]`.
- Every note has frontmatter with at least `status` (`draft` / `active` / `stable` / `archived`) and `tags`.
- Significant decisions get a note in `06 Decisions/` (use the Decision template) and a row in the [[Decision Log]].
- Unresolved questions go in [[Open Questions]]. When answered, fold the answer into the relevant note and log the decision.
- Images and files go in `Attachments/`.

## Folder map
| Folder | Purpose |
|---|---|
| `01 Vision` | Concept, principles, personas, customer experience — the north star |
| `02 Business` | Business model, market, Kickstarter plan |
| `03 Prototyping` | Prototype plans and build logs (practical, constrained) |
| `04 Engineering` | Subsystem design: fluidics, electronics, firmware, mechanical, horticulture |
| `05 Design` | Industrial design, brand, renders, moodboards |
| `06 Decisions` | Decision records and log |
| `07 Meetings` | Meeting notes |
| `08 Research` | User research, horticulture research, competitor teardown notes |
| `Templates` | Note templates |
| `Attachments` | Images, sketches, PDFs |
